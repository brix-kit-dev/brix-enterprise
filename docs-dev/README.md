## 维护规则

- 新增文档时在本页登记。
- 蓝图版本和施工方案只在 `docs/README.md` 登记。
- 历史版本不得留在本目录根部与在用文档并列；迁移到 `archived/` 后保留原文件名。
- 跨目录引用优先指向在用文档，不引用已归档文档，除非是在解释历史背景。
