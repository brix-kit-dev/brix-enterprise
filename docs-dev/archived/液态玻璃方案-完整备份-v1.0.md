# 液态玻璃（Liquid Glass）完整方案备份 v1.0

> **归档日期**：2026-05-17  
> **归档原因**：BrixUI 主风格定位为「Refined Flat（劳模模式）」，玻璃方案退役。本文档完整保留实现细节，供未来「高端版 / 营销页 / 命令面板 / Modal 遮罩」等点睛场景复用，或未来 GPU/浏览器能力进化后整体复活时使用。  
> **关联代码版本**：`@brix-sdk/platform-frame-web` 退役前最后一次构建（622ms 通过）  
> **作用范围**：`ProtectedLayout`（主内容区）+ `AppSidebar` + `AppHeader` 三处面板。

---

## 一、设计原则（务必记住）

1. **4 层结构**（每个玻璃面板都套这套）：
   - `wrapper`（透明 + border + shadow + isolation:isolate）
   - `effect`（z=0）→ backdrop-filter:blur + filter:url(#svg) **黄金组合**，缺一不可
   - `tint`（z=1）→ 深色 token + saturate/contrast/brightness
   - `sheen-sharp`（z=2）→ demo 经典双角 1px 锐光
   - `sheen-reflect`（z=3）→ 软晕 + 1px 外环
   - 内容（z=4）

2. **`filter: url(#f)` 必须与 `backdrop-filter: blur(3px)` 同层叠加**——这是 Chrome/Safari 唯一能稳定让「背景被位移扭曲」的可靠路径。单独 `backdrop-filter: url()` 在大多数环境失效。

3. **环境光底色不可省**：纯白背景 + blur 后还是纯白，玻璃感为零。必须有 radial-gradient 多色斑提供「可被折射的色相变化」。

4. **token 唯一真相源**：所有颜色经 `tokens.colors.*` + `withAlpha()`，零硬编码。

## 二、环境光底色（ProtectedLayout containerStyle）

```ts
const pageBaseColor = tokens.colors.surface.page;
const ambientPrimaryStrong = withAlpha(tokens.colors.brand.primary, 0.20);
const ambientPrimarySoft   = withAlpha(tokens.colors.brand.primary, 0.13);
const ambientAccentStrong  = withAlpha(tokens.colors.brand.secondary, 0.18);
const ambientAccentSoft    = withAlpha(tokens.colors.brand.secondary, 0.12);
const ambientInfoStrong    = withAlpha(tokens.colors.status.info, 0.15);
const ambientInfoSoft      = withAlpha(tokens.colors.status.info, 0.10);

const pageBackground = [
  `radial-gradient(circle at 88% 92%, ${ambientPrimaryStrong} 0%, transparent 52%)`,
  `radial-gradient(circle at 8% 88%,  ${ambientAccentStrong}  0%, transparent 50%)`,
  `radial-gradient(circle at 92% 6%,  ${ambientInfoStrong}    0%, transparent 48%)`,
  `radial-gradient(circle at 10% 10%, ${ambientAccentSoft}    0%, transparent 46%)`,
  `radial-gradient(circle at 50% 50%, ${ambientPrimarySoft}   0%, transparent 60%)`,
  `radial-gradient(circle at 70% 30%, ${ambientInfoSoft}      0%, transparent 44%)`,
  pageBaseColor,
].join(', ');

// containerStyle
{
  background: pageBackground,
  color: tokens.colors.text.primary,
  fontFamily: tokens.typography.fontFamily,
  isolation: 'isolate',
}
```

## 三、玻璃面板 4 层结构（以 ProtectedLayout 主内容区为例）

### 3.1 wrapper（contentStyle）

```ts
{
  flex: 1,
  height: `calc(100vh - ${headerHeight + 40}px)`,
  position: 'relative',
  overflow: 'hidden',
  background: 'transparent', // 关键：外层必须透明
  border: `1px solid ${withAlpha(tokens.colors.text.primary, 0.10)}`,
  borderRadius: shellGlassRadius,
  boxShadow:
    `0 30px 80px ${withAlpha(tokens.colors.text.primary, 0.10)}, ` +
    `0 8px 24px ${withAlpha(tokens.colors.text.primary, 0.06)}`,
}
// shellGlassRadius = `calc(${tokens.shape.lg} + ${tokens.space.sm})`
```

### 3.2 effect 层（z=0）— **demo 黄金组合**

```ts
{
  position: 'absolute',
  inset: 0,
  zIndex: 0,
  pointerEvents: 'none',
  borderRadius: shellGlassRadius,
  overflow: 'hidden',
  isolation: 'isolate',
  backdropFilter: 'blur(3px)',
  WebkitBackdropFilter: 'blur(3px)',
  filter: `url(#${FILTER_ID})`,
}
```

### 3.3 tint 层（z=1）— 深色玻璃

```ts
{
  position: 'absolute',
  inset: 0,
  zIndex: 1,
  pointerEvents: 'none',
  borderRadius: shellGlassRadius,
  backgroundColor: withAlpha(tokens.colors.text.primary, 0.12),
  backdropFilter: 'saturate(160%) contrast(110%) brightness(105%)',
  WebkitBackdropFilter: 'saturate(160%) contrast(110%) brightness(105%)',
}
```

> ⚠️ **复活时必修**：把 `text.primary` 换成新增的 `surface.glassScrim` 语义 token，避免 dark 模式反转。

### 3.4 sheen-sharp 层（z=2）— demo 经典 1px 双角锐光

```ts
{
  position: 'absolute',
  inset: 0,
  zIndex: 2,
  pointerEvents: 'none',
  borderRadius: shellGlassRadius,
  boxShadow:
    `inset 2px 2px 1px 0 ${withAlpha(tokens.colors.surface.card, 0.62)}, ` +
    `inset -1px -1px 1px 1px ${withAlpha(tokens.colors.surface.card, 0.5)}`,
}
```

### 3.5 sheen-reflect 层（z=3）— 厚玻璃倒角软晕

```ts
{
  position: 'absolute',
  inset: 0,
  zIndex: 3,
  pointerEvents: 'none',
  borderRadius: shellGlassRadius,
  boxShadow:
    `inset 6px 6px 18px -3px ${withAlpha(tokens.colors.surface.card, 0.35)}, ` +
    `inset -5px -5px 18px -3px ${withAlpha(tokens.colors.surface.card, 0.30)}, ` +
    `inset 0 0 0 1px ${withAlpha(tokens.colors.surface.card, 0.42)}`,
}
```

### 3.6 inner 内容层（z=4）

```ts
{ position: 'relative', zIndex: 4, height: '100%', overflow: 'auto' }
```

## 四、SVG 位移滤镜（每个面板独立一份，seed 不同避免视觉同步）

```tsx
<svg aria-hidden="true" focusable="false"
     style={{ position: 'absolute', width: 0, height: 0, overflow: 'hidden' }}>
  <filter id={FILTER_ID} x="-20%" y="-20%" width="140%" height="140%">
    {/* 1. 中频湍流，三八度多尺度 */}
    <feTurbulence type="fractalNoise"
                  baseFrequency="0.012 0.018"
                  numOctaves="3"
                  seed="21"            {/* content=21, sidebar=13, header=8 */}
                  result="noise" />
    {/* 2. 软化噪声去颗粒 */}
    <feGaussianBlur in="noise" stdDeviation="2" result="softNoise" />
    {/* 3. 位移：content=50, sidebar=55, header=45 */}
    <feDisplacementMap in="SourceGraphic" in2="softNoise"
                       scale="50"
                       xChannelSelector="R" yChannelSelector="G"
                       result="displaced" />
    {/* 4. 模拟色散 */}
    <feColorMatrix in="displaced" type="saturate" values="1.22" />
  </filter>
</svg>
```

**filter id 命名**（必须各自独立）：
- `brix-content-liquid-glass-distortion`
- `brix-sidebar-liquid-glass-distortion`
- `brix-header-liquid-glass-distortion`

## 五、JSX 渲染顺序（DOM 序 == z-index 序）

```tsx
<div style={containerStyle}>  {/* 或 sidebarStyle / headerStyle */}
  <svg>…filter…</svg>
  <div aria-hidden style={effectStyle} />        {/* z=0 */}
  <div aria-hidden style={tintStyle} />          {/* z=1 */}
  <div aria-hidden style={sheenStyle} />         {/* z=2 sharp */}
  <div aria-hidden style={sheenReflectStyle} />  {/* z=3 reflect */}
  <div style={innerStyle}>{children}</div>       {/* z=4 */}
</div>
```

## 七、复活时的必修项（务必先做）

1. **新增 token**：在 `@brix-sdk/platform-design-tokens` 增加 `surface.glassScrim`（light/dark 两套值），替换所有 `text.primary` 用作背景 tint 的地方
2. **抽组件**：封装 `<LiquidGlass radius tint filterId children>`，外部插件作者只用组件不接触 4 层细节
3. **降级路径**：监听 `prefers-reduced-transparency` 和 `prefers-reduced-motion`，命中时退化为 `surface.card + 1px border + shadow.sm`
4. **打印降级**：`@media print { .liquid-glass { backdrop-filter: none; background: tokens.surface.card } }`
5. **对比度审计**：所有玻璃面板上文字必须过 WCAG AA 4.5:1
6. **性能预算**：仅在「短暂出现」或「小面积」场景启用——`<CommandPalette>` `<Modal scrim>` `<HeaderOverlay>` `<Toast>`；**禁止**用于 `<Sidebar>` `<DataTable>` 等长期可见或高密度内容
