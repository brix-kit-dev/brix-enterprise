# Contributing to Brix Enterprise

This is a proprietary project. Contributions are limited to authorized team members.

## Development Guidelines

1. All code must include the proprietary header comment
2. Never commit secrets or credentials
3. Follow the established architecture patterns
4. All changes require code review

## Code Header

All source files must include:

```java
/*
 * Copyright 2026 Brix Platform Authors
 *
 * Brix Enterprise License - All Rights Reserved
 *
 * PROPRIETARY AND CONFIDENTIAL
 * Unauthorized copying or distribution of this file is strictly prohibited.
 * Commercial use requires a valid Brix Enterprise license.
 */
```

## Security

- Never commit .env files, keys, or credentials
- Use environment variables for sensitive configuration
- Follow the principle of least privilege
