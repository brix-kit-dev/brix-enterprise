## 🎯 v0.1 MVP 骨架设计（本文档重点）

### MVP 设计原则

```text
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              MVP 骨架设计原则                                            │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                          │
│  【不可推翻的骨架】这些决策一旦确定，后续版本只能扩展，不能推翻                          │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│                                                                                          │
│  1. 数据模型：三层身份模型（Identity → Membership → Profile）                            │
│     • 为什么不可变：数据库表结构，后续只能加字段，不能改主键关系                         │
│                                                                                          │
│  2. Token 结构：JWT 包含 tid / tcode / uid / mid / mtype                                │
│     • 为什么不可变：已签发的 Token 无法修改，结构必须前向兼容                            │
│                                                                                          │
│  3. 上下文传递：TenantContext 基于 ThreadLocal + Reactive Context                       │
│     • 为什么不可变：所有业务代码都会依赖这个 API                                         │
│                                                                                          │
│  4. 数据隔离：tenant_id 字段 + 拦截器自动过滤                                            │
│     • 为什么不可变：所有业务表都会加 tenant_id，拦截机制统一                             │
│                                                                                          │
│  【可以后续扩展的能力】                                                                  │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│                                                                                          │
│  • 租户解析器：MVP 只做 JWT 解析，后续加子域名/Path 解析（责任链模式天然支持）           │
│  • 隔离级别：MVP 只做行级隔离，后续加 Schema/Database 隔离（适配器模式天然支持）         │
│  • 登录流程：MVP 只做单租户自动进入，后续加租户选择器（前端扩展）                        │
│  • 管理界面：MVP 用命令行/SQL，后续加 Web 界面（独立插件）                               │
│                                                                                          │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### MVP 交付范围

| 模块 | MVP 范围 | 后续扩展 |
|------|----------|----------|
| **数据模型** | sys_tenant + sys_identity + sys_tenant_member | biz_user_profile 由业务插件定义 |
| **认证** | 手机号登录 → 单租户自动进入 → JWT Token | 多租户选择、OAuth、SSO |
| **Token** | 包含 tid/tcode/uid/mid/mtype | 权限引用、设备绑定 |
| **上下文** | TenantContext.getCurrentTenantId() | 异步任务装饰器、Reactive 扩展 |
| **数据隔离** | MyBatis 拦截器 + 行级过滤 | Schema 隔离、Database 隔离 |
| **租户解析** | JWT Token 解析 | 子域名、Path、Header 解析 |
| **租户管理** | SQL 脚本创建租户 | Web 界面、自助注册 |
| **前端** | 无（后端优先） | TenantContext Hook、品牌切换 |

## 1. 设计目标与原则

### 1.1 设计目标

```text
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              多租户架构设计目标                                          │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                          │
│  🎯 核心目标                                                                             │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│  1. 通用性：适用于医疗中介、电商、企业服务等任意 SaaS 场景                               │
│  2. 可扩展：从单租户平滑演进到百万级租户                                                 │
│  3. 安全隔离：租户数据严格隔离，符合 SOC2、GDPR 等合规要求                               │
│  4. 商业化：支持开源版与商业版的功能差异化                                               │
│  5. 开发友好：插件开发者无需感知多租户复杂性                                             │
│                                                                                          │
│  📊 量化指标                                                                             │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│  • 开源版支持租户数：≤ 3 个                                                              │
│  • 商业版支持租户数：无上限（按 License 计费）                                           │
│  • 租户切换延迟：< 100ms                                                                 │
│  • 跨租户数据泄露风险：零容忍                                                            │
│                                                                                          │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 设计原则

| 原则 | 说明 | 参考来源 |
|------|------|----------|
| **租户即边界** | 租户是数据、配置、计费的最小隔离单元 | AWS SaaS Factory |
| **身份与租户分离** | 用户身份是全局的，租户成员关系是多对多 | Azure AD B2C |
| **默认安全** | 所有数据访问默认带租户过滤，需显式声明跨租户 | Salesforce |
| **配置优于代码** | 租户特性通过配置实现，非硬编码 | 12-Factor App |
| **能力契约化** | 多租户能力作为 Runtime Capability 提供 | Brix 运行壳架构 |

### 2.3 租户属性模型

```typescript
/**
 * 租户核心属性（平台级）
 */
interface Tenant {
  // === 基础标识 ===
  id: string;                    // 租户唯一ID（UUID）
  code: string;                  // 租户编码（用于URL/子域名，如 "acme"）
  name: string;                  // 租户显示名称
  
  // === 生命周期 ===
  status: TenantStatus;          // PENDING | TRIAL | ACTIVE | SUSPENDED | CANCELLED | DELETED
  createdAt: DateTime;
  activatedAt?: DateTime;
  expiresAt?: DateTime;          // 试用/订阅到期时间
  
  // === 订阅与计费（商业版） ===
  plan: TenantPlan;              // FREE | STARTER | PROFESSIONAL | ENTERPRISE
  billingEmail?: string;
  
  // === 配额（商业版） ===
  quotas: TenantQuotas;
  
  // === 品牌配置 ===
  branding: TenantBranding;
  
  // === 功能开关 ===
  features: Record<string, boolean>;
  
  // === 数据隔离 ===
  isolationLevel: IsolationLevel; // ROW | SCHEMA | DATABASE
  region: string;                 // 数据存储区域（CN | GLOBAL | JP）
}

interface TenantQuotas {
  maxUsers: number;               // 最大用户数
  maxStorage: number;             // 最大存储（MB）
  maxApiCalls: number;            // 每月 API 调用数
  // 业务级配额由插件定义
  customQuotas: Record<string, number>;
}

interface TenantBranding {
  logoUrl?: string;
  primaryColor?: string;
  faviconUrl?: string;
  customDomain?: string;          // 自定义域名（商业版）
  loginPageConfig?: LoginPageConfig;
}

type TenantStatus = 'PENDING' | 'TRIAL' | 'ACTIVE' | 'SUSPENDED' | 'CANCELLED' | 'DELETED';
type TenantPlan = 'FREE' | 'STARTER' | 'PROFESSIONAL' | 'ENTERPRISE';
type IsolationLevel = 'ROW' | 'SCHEMA' | 'DATABASE';
```

## 3. 身份与认证架构

### 3.1 三层身份模型

```text
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              三层身份模型                                                │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                          │
│  Layer 1: Identity（全局身份）                                                           │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│  • 用户在平台级别的唯一身份                                                              │
│  • 与认证凭证绑定（手机号/邮箱/OAuth）                                                   │
│  • 跨租户共享，一个手机号 = 一个 Identity                                                │
│                                                                                          │
│       ┌─────────────────────────────────────────────────────────────────────────────┐   │
│       │  sys_identity                                                               │   │
│       │──────────────────────────────────────────────────────────────────────────── │   │
│       │  id          │ 全局唯一ID (UUID)                                            │   │
│       │  phone       │ 手机号（唯一索引，可为空）                                    │   │
│       │  email       │ 邮箱（唯一索引，可为空）                                      │   │
│       │  username    │ 用户名（唯一索引，可为空）                                    │   │
│       │  password_hash│ 密码哈希（Argon2id）                                         │   │
│       │  mfa_enabled │ 是否启用 MFA                                                 │   │
│       │  status      │ ACTIVE / LOCKED / DISABLED                                   │   │
│       │  created_at  │                                                              │   │
│       │  last_login_at│                                                             │   │
│       └─────────────────────────────────────────────────────────────────────────────┘   │
│                                      │                                                   │
│                                      │ 1:N                                               │
│                                      ▼                                                   │
│  Layer 2: Tenant Membership（租户成员关系）                                              │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│  • 用户与租户的关联关系                                                                  │
│  • 一个用户可以属于多个租户                                                              │
│  • 记录用户在该租户的角色类型                                                            │
│                                                                                          │
│       ┌─────────────────────────────────────────────────────────────────────────────┐   │
│       │  sys_tenant_member                                                          │   │
│       │──────────────────────────────────────────────────────────────────────────── │   │
│       │  id          │ 成员关系ID                                                   │   │
│       │  tenant_id   │ 租户ID（FK → sys_tenant）                                    │   │
│       │  identity_id │ 身份ID（FK → sys_identity）                                  │   │
│       │  member_type │ OWNER / ADMIN / MEMBER / CUSTOMER / GUEST                    │   │
│       │  status      │ ACTIVE / INVITED / DISABLED                                  │   │
│       │  invited_by  │ 邀请人                                                       │   │
│       │  joined_at   │                                                              │   │
│       │  UNIQUE(tenant_id, identity_id)                                             │   │
│       └─────────────────────────────────────────────────────────────────────────────┘   │
│                                      │                                                   │
│                                      │ 1:1                                               │
│                                      ▼                                                   │
│  Layer 3: Tenant User Profile（租户内用户档案）                                          │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│  • 用户在具体租户内的业务数据                                                            │
│  • 完全隔离在租户数据空间内                                                              │
│  • 由业务插件扩展（如医疗中介的患者档案）                                                │
│                                                                                          │
│       ┌─────────────────────────────────────────────────────────────────────────────┐   │
│       │  biz_user_profile（租户隔离表）                                             │   │
│       │──────────────────────────────────────────────────────────────────────────── │   │
│       │  id          │ 租户内用户ID                                                 │   │
│       │  tenant_id   │ 租户ID（分区键）                                             │   │
│       │  member_id   │ 成员关系ID（FK → sys_tenant_member）                         │   │
│       │  nickname    │ 租户内昵称                                                   │   │
│       │  avatar_url  │ 头像                                                         │   │
│       │  preferences │ JSONB 用户偏好                                               │   │
│       │  extended    │ JSONB 业务扩展字段                                           │   │
│       │  created_at  │                                                              │   │
│       │  updated_at  │                                                              │   │
│       └─────────────────────────────────────────────────────────────────────────────┘   │
```

```java
/**
 * MyBatis 租户拦截器 - 自动添加租户过滤条件
 */
@Intercepts({
    @Signature(type = Executor.class, method = "query", 
               args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class}),
    @Signature(type = Executor.class, method = "update", 
               args = {MappedStatement.class, Object.class})
})
@Component
public class TenantInterceptor implements Interceptor {
    
    // 不需要租户隔离的表（平台级表）
    private static final Set<String> EXCLUDED_TABLES = Set.of(
        "sys_tenant", "sys_identity", "sys_tenant_member", "sys_identity_oauth"
    );
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        MappedStatement ms = (MappedStatement) invocation.getArgs()[0];
        Object parameter = invocation.getArgs()[1];
        
        // 跳过平台级表
        if (isExcludedTable(ms)) {
            return invocation.proceed();
        }
        
        // 获取当前租户（从 ThreadLocal / SecurityContext）
        String tenantId = TenantContext.getCurrentTenantId();
        if (tenantId == null) {
            throw new TenantRequiredException("Tenant context is required for this operation");
        }
        
        // 修改 SQL 添加租户条件
        BoundSql boundSql = ms.getBoundSql(parameter);
        String originalSql = boundSql.getSql();
        String modifiedSql = addTenantCondition(originalSql, tenantId);
        
        // 重新构建 MappedStatement
        // ... 省略具体实现
        
        return invocation.proceed();
    }
}
```

```java
/**
 * JPA 实体基类 - 自动填充租户ID
 */
@MappedSuperclass
@EntityListeners(TenantEntityListener.class)
public abstract class TenantAwareEntity {
    
    @Column(name = "tenant_id", nullable = false, updatable = false)
    private String tenantId;
    
    // Hibernate Filter 定义
    @FilterDef(name = "tenantFilter", parameters = @ParamDef(name = "tenantId", type = String.class))
    @Filter(name = "tenantFilter", condition = "tenant_id = :tenantId")
    // ... getter/setter
}

/**
 * 租户实体监听器 - 自动填充租户ID
 */
@Component
public class TenantEntityListener {
    
    @PrePersist
    public void prePersist(TenantAwareEntity entity) {
        if (entity.getTenantId() == null) {
            entity.setTenantId(TenantContext.getCurrentTenantId());
        }
    }
    
    @PreUpdate
    @PreRemove
    public void preModify(TenantAwareEntity entity) {
        // 验证租户一致性，防止跨租户修改
        String currentTenant = TenantContext.getCurrentTenantId();
        if (!entity.getTenantId().equals(currentTenant)) {
            throw new CrossTenantAccessException("Cannot modify entity from different tenant");
        }
    }
```

### 5.2 租户解析器实现

```java
/**
 * 租户解析器链 - 责任链模式
 */
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class TenantResolverFilter implements WebFilter {
    
    private final List<TenantResolver> resolvers;
    private final TenantService tenantService;
    
    public TenantResolverFilter(List<TenantResolver> resolvers, TenantService tenantService) {
        // 按优先级排序
        this.resolvers = resolvers.stream()
            .sorted(Comparator.comparingInt(TenantResolver::getOrder))
            .toList();
        this.tenantService = tenantService;
    }
    
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, WebFilterChain chain) {
        // 按优先级尝试解析
        for (TenantResolver resolver : resolvers) {
            Optional<String> tenantId = resolver.resolve(exchange);
            if (tenantId.isPresent()) {
                // 验证租户存在且有效
                Tenant tenant = tenantService.getActiveTenant(tenantId.get());
                if (tenant != null) {
                    // 设置到上下文
                    TenantContext.setCurrentTenant(tenant);
                    exchange.getAttributes().put("tenant", tenant);
                    break;
                }
            }
        }
        
        return chain.filter(exchange)
            .contextWrite(ctx -> ctx.put(TenantContext.KEY, TenantContext.getCurrentTenant()))
            .doFinally(signal -> TenantContext.clear());
    }
}

/**
 * JWT Token 租户解析器
 */
@Component
@Order(100)
public class JwtTenantResolver implements TenantResolver {
    
    @Override
    public Optional<String> resolve(ServerWebExchange exchange) {
        String authHeader = exchange.getRequest().getHeaders().getFirst("Authorization");
        if (authHeader != null && authHeader.startsWith("Bearer ")) {
            String token = authHeader.substring(7);
            try {
                Claims claims = jwtParser.parseClaimsJws(token).getBody();
                return Optional.ofNullable(claims.get("tid", String.class));
            } catch (JwtException e) {
                return Optional.empty();
            }
        }
        return Optional.empty();
    }
    
    @Override
    public int getOrder() {
        return 100; // 最高优先级
    }
}

/**
 * 子域名租户解析器
 */
@Component
@Order(300)
public class SubdomainTenantResolver implements TenantResolver {
    
    private final Pattern subdomainPattern = Pattern.compile("^([a-z0-9-]+)\\.console\\.brix\\.com$");
    
    @Override
    public Optional<String> resolve(ServerWebExchange exchange) {
        String host = exchange.getRequest().getHeaders().getHost().getHostString();
        Matcher matcher = subdomainPattern.matcher(host);
        if (matcher.matches()) {
            String tenantCode = matcher.group(1);
            // 通过 code 查找 tenant_id
            return tenantService.findTenantIdByCode(tenantCode);
        }
        return Optional.empty();
    }
    
    @Override
    public int getOrder() {
        return 300;
    }
}
```

```java
/**
 * 租户上下文 - 贯穿整个请求生命周期
 */
public class TenantContext {
    
    private static final ThreadLocal<Tenant> CURRENT_TENANT = new ThreadLocal<>();
    
    // Reactive 上下文 Key
    public static final String KEY = "TENANT_CONTEXT";
    
    public static void setCurrentTenant(Tenant tenant) {
        CURRENT_TENANT.set(tenant);
    }
    
    public static Tenant getCurrentTenant() {
        return CURRENT_TENANT.get();
    }
    
    public static String getCurrentTenantId() {
        Tenant tenant = CURRENT_TENANT.get();
        return tenant != null ? tenant.getId() : null;
    }
    
    public static void clear() {
        CURRENT_TENANT.remove();
    }
    
    // 异步任务装饰器 - 传递租户上下文
    public static Runnable wrap(Runnable task) {
        Tenant tenant = getCurrentTenant();
        return () -> {
            try {
                setCurrentTenant(tenant);
                task.run();
            } finally {
                clear();
            }
        };
    }
    
    public static <T> Callable<T> wrap(Callable<T> task) {
        Tenant tenant = getCurrentTenant();
        return () -> {
            try {
                setCurrentTenant(tenant);
                return task.call();
            } finally {
                clear();
            }
        };
    }
}

/**
 * 租户感知的线程池
 */
@Configuration
public class TenantAwareExecutorConfig {
    
    @Bean
    public TaskExecutor taskExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(10);
        executor.setMaxPoolSize(50);
        executor.setTaskDecorator(runnable -> TenantContext.wrap(runnable));
        executor.initialize();
        return executor;
    }
}

/**
 * 服务间调用 - 自动传递租户
 */
@Component
public class TenantPropagationInterceptor implements ClientHttpRequestInterceptor {
    
    @Override
    public ClientHttpResponse intercept(HttpRequest request, byte[] body, 
            ClientHttpRequestExecution execution) throws IOException {
        
        String tenantId = TenantContext.getCurrentTenantId();
        if (tenantId != null) {
            request.getHeaders().add("X-Tenant-Id", tenantId);
        }
        
        return execution.execute(request, body);
    }
}
```

```java
            }
        }
```

```typescript
interface TenantContextValue {
  tenant: Tenant | null;
  isLoading: boolean;
  error: Error | null;
  switchTenant: (tenantId: string) => Promise<void>;
  refreshTenant: () => Promise<void>;
}

const TenantContext = createContext<TenantContextValue | undefined>(undefined);

export function TenantProvider({ children }: { children: React.ReactNode }) {
  const [tenant, setTenant] = useState<Tenant | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const { token, setToken } = useAuth();
  
  useEffect(() => {
    // 从 Token 中提取租户信息
    if (token) {
      const decoded = jwtDecode<TokenPayload>(token);
      if (decoded.tid) {
        loadTenant(decoded.tid);
      }
    } else {
      // 未登录状态，尝试从 URL 解析租户（用于登录页品牌展示）
      const tenantCode = extractTenantFromUrl();
      if (tenantCode) {
        loadTenantByCode(tenantCode);
      }
    }
  }, [token]);
  
  const switchTenant = async (tenantId: string) => {
    // 调用后端切换租户 API
    const response = await api.post('/auth/switch-tenant', { tenantId });
    setToken(response.token);
    setTenant(response.tenant);
  };
  
  return (
    <TenantContext.Provider value={{ tenant, isLoading, error, switchTenant, refreshTenant }}>
      {children}
    </TenantContext.Provider>
  );
}

export function useTenant() {
  const context = useContext(TenantContext);
  if (!context) {
    throw new Error('useTenant must be used within TenantProvider');
  }
  return context;
}
```

```java
/**
 * 跨租户访问注解 - 必须显式声明
 */
@Target({ElementType.METHOD, ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
public @interface CrossTenantAccess {
    /**
     * 访问理由（用于审计）
     */
    String reason();
    
    /**
     * 需要的权限
     */
    String[] permissions() default {};
    
    /**
     * 是否需要审批
     */
    boolean requireApproval() default false;
}

/**
 * 跨租户访问切面
 */
@Aspect
@Component
public class CrossTenantAccessAspect {
    
    private final AuditLogService auditLogService;
    private final ApprovalService approvalService;
    
    @Around("@annotation(crossTenantAccess)")
    public Object around(ProceedingJoinPoint joinPoint, CrossTenantAccess crossTenantAccess) 
            throws Throwable {
        
        String currentTenant = TenantContext.getCurrentTenantId();
        String targetTenant = extractTargetTenant(joinPoint);
        
        if (!currentTenant.equals(targetTenant)) {
            // 记录跨租户访问
            auditLogService.logCrossTenantAccess(
                currentTenant, 
                targetTenant, 
                crossTenantAccess.reason(),
                joinPoint.getSignature().toString()
            );
            
            // 检查审批
            if (crossTenantAccess.requireApproval()) {
                if (!approvalService.isApproved(currentTenant, targetTenant, "cross_tenant_access")) {
                    throw new CrossTenantAccessDeniedException(
                        "Cross-tenant access requires approval"
                    );
                }
            }
            
            // 检查权限
            checkPermissions(crossTenantAccess.permissions());
        }
        
        return joinPoint.proceed();
    }
}
```

```text
│  • 拦截 INSERT → 自动填充 tenant_id 字段                                                │
│  • 拦截 UPDATE/DELETE → 验证 tenant_id 一致性                                           │
│  • 排除列表：sys_tenant, sys_identity, sys_tenant_member                                │
│                                                                                          │
│  【登录流程 - 最简实现】                                                                 │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│  1. POST /api/auth/login { phone, code }                                                │
│  2. 验证手机号 + 验证码                                                                 │
│  3. 查找 sys_identity → 查找 sys_tenant_member                                          │
│  4. 如果只有一个成员关系 → 直接返回 Token                                               │
│  5. 如果有多个成员关系 → 返回第一个（MVP简化，后续加选择器）                            │
│                                                                                          │
│  【开发环境默认租户】                                                                    │
│  ════════════════════════════════════════════════════════════════════════════════════   │
│  配置：brix.tenant.default-tenant-id = "default"                                        │
│  行为：如果请求没有租户上下文 + 开发环境 → 使用默认租户                                 │
│                                                                                          │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### 12.3 MVP 验收标准

| 验收项 | 验收标准 |
|--------|----------|
| **数据隔离** | 租户A的用户无法查询到租户B的数据 |
| **登录流程** | 手机号登录后，JWT Token 包含正确的 tid |
| **上下文传递** | Controller 中可以通过 TenantContext.getCurrentTenantId() 获取租户 |
| **自动过滤** | SELECT 语句自动添加 tenant_id 条件 |
| **自动填充** | INSERT 语句自动填充 tenant_id 字段 |
| **开发环境** | 无 Token 时使用默认租户（仅开发环境） |

|------|------|
| **Tenant** | 租户，独立的业务实体，是数据隔离和计费的基本单位 |
| **Identity** | 身份，用户的全局唯一标识，与认证凭证绑定 |

| **Isolation Level** | 隔离级别，数据隔离的策略（Row/Schema/Database） |
| **Tenant Context** | 租户上下文，在请求生命周期内传递的租户信息 |
